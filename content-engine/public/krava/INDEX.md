## Start here (suggested first post / first ad set)
1. **Post `01-thickness-test/krava-thickness-test-en.mp4` organic** on TikTok + IG Reels
   with trending audio (you can mute the VO for organic). It has the best hook.
2. Run **02 + 04** as the first **paid** A/B (proof angle vs convenience angle), small budget.
3. Watch 3-sec hook rate + CThru. Kill losers in 48h, scale the winner's angle into 3 fresh variants.

## Before you spend real media budget (read `AD-MATRIX.md` → Compliance)
- Composite the **real Krava jar/label** on every end frame (AI vessels are intentionally unbranded).
- No "−20%" badge until the base price has run 30 days (Swiss OPD).
- No gut/digestion/medical claims; no "14 cultures" number until verified.
