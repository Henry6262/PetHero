## GENERATION TIPS

| Tip | Why It Matters |
|-----|---------------|
| Use **16:9 ratio** | Matches standard video format |
| Keep clips **4-5 seconds** | Long enough to see, short enough to cut |
| Include "**photorealistic, 4K**" in every prompt | Gets best quality |
| Generate **2-3 variants** of each | Pick the best one |
| Download as **MP4** | Universal format |
| Name files: `clip_A_walk.mp4`, `clip_B_fly.mp4`, etc. | Easy to find when editing |
