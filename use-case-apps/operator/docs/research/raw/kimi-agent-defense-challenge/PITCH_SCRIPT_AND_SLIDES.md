# SCOUT C2 — 3-Minute Pitch Script & Slide Deck
## You talk. The slides show. Almost zero text. Pure visual storytelling.

---

## THE RULES

- **You talk the entire 3 minutes.** The slides are visual backup.
- **Almost zero text on slides.** Icons, images, screenshots, maps — no bullet points.
- **One idea per slide.** Don't cram. Let each image breathe.
- **The narrative arc:** Problem → System → Demo → Proof → Impact.

## PRESENTATION FORMAT

### What You Actually Show

You have two options for displaying slides:

**Option A: PowerPoint / Keynote / Google Slides**
- Create 10 slides with the visuals described above
- Full-screen presentation mode
- You control advancement with arrow keys or a clicker
- **Best for:** Reliable, professional, easy to practice

**Option B: HTML Presentation (Reveal.js / Impress.js)**
- Single HTML file with 10 fullscreen slides
- Transitions: fade, slide, zoom
- Can embed videos directly
- **Best for:** Embedding the 3D animation video, web-native

### How to Get the Screenshots

**Admin dashboard screenshot:**
1. Run your Flask server
2. Open `http://localhost:5050/admin` in Chrome
3. Press F11 (fullscreen)
4. Let the simulation run for 30 seconds (agents move, coverage grows)
5. Screenshot: `Command+Shift+4` (Mac) or `Win+Shift+S` (Windows)

**Mobile app screenshots:**
1. Open `http://localhost:5050/operator` in Chrome
2. DevTools → Toggle Device Toolbar → select iPhone 13/14
3. Let simulation run
4. Screenshot the threat detected screen, the squad dashboard, the change detection screen

**3D village animation video:**
1. Run your Three.js 3D view
2. Use OBS to record the browser window
3. Narrate the drop, sweep, threat, recon scenes
4. Save as MP4, embed in Slide 5 and Slide 8

## PRACTICE NOTES

### Timing Drill

1. Set a timer for 3 minutes
2. Run through all 10 slides while narrating
3. Note where you go over/under
4. Adjust — cut words, not slides
5. Repeat 5 times minimum

### Common Timing Mistakes

| Mistake | Fix |
|---|---|
| Slide 1-2 too long (spend 40s on problem) | Cut Slide 2 text, keep the image |
| Slide 5 animation runs too long | Pre-render a 10-second clip, loop if needed |
| Slide 7 live robot hesitates | Practice the robot walk 10 times before the demo |
| Running over 3 minutes | Cut 2-3 words from every sentence |
| Under 2:30 | Pause longer on Slide 1 and Slide 10 |

### Backup Plan

If the live robot fails during Slide 7:
- Have a **15-second video backup** of the robot walking
- Pre-record it at the venue before the demo
- If robot doesn't move on cue: "Let me show you a recording from earlier today" → play video

If the 3D animation stutters:
- Have a **GIF or looping video** instead of live Three.js
- Pre-render 10 seconds, loop it
