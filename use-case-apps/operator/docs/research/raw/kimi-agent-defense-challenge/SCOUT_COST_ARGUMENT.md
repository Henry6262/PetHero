## THE TALKING POINTS (Use These Exact Lines)

### 1. The Price Tag Comparison
```
"Boston Dynamics Spot: seventy-four thousand five hundred dollars. 
It walks. It inspects. It doesn't fly. It doesn't coordinate drones.

SCOUT Mini: five hundred sixty-seven dollars. 
It walks. It flies. It coordinates six drones. It maps buildings in 3D.
That's one hundred thirty-one times cheaper."
```

### 2. The Fleet Math
```
"For the price of ONE Spot robot, you can build ONE HUNDRED AND THIRTY-ONE 
SCOUT Minis. That's not a robot. That's a swarm."
```

### 3. The Kamikaze vs Reusable Argument
```
"A US Switchblade loitering munition costs fifty-three thousand dollars 
and it's single-use. It crashes into the target and it's gone.

SCOUT costs five hundred sixty-seven dollars and it comes back. 
Every mission. It walks in, it scouts, it flies out, it recharges, 
it goes again. The cost-per-mission drops to near zero."
```

### 4. The Ukraine Context
```
"Russia's Lancet drone costs forty thousand dollars per unit. 
Ukraine's Bulava costs six to ten thousand. 
SCOUT costs five hundred sixty-seven — and it's reusable, 
not single-use kamikaze."
```

### 5. The 3D Printer Argument
```
"The 3D printer is four hundred forty-nine dollars. 
That's the manufacturing line. Print the body. Print the legs. 
Print the rotor arms. Six iterations in one week. 

Boston Dynamics takes eight to twelve weeks to ship one Spot. 
We can print six SCOUTs in one week for less than the shipping cost 
of one Spot."
```

### 6. The Capability-Per-Dollar Winner
```
"Spot gives you three capabilities for seventy-five thousand dollars. 
SCOUT gives you eight capabilities for five hundred sixty-seven dollars. 

That's twenty-one times more capability per dollar."
```

## IF JUDGES PUSH BACK

### "A $567 robot can't be as good as a $75,000 Spot"

**Response:**
```
"Spot doesn't fly. Spot doesn't share a map with operator phones. 
Spot doesn't coordinate drone swarms. Spot doesn't have an ambush mode.

We're not competing with Spot on industrial inspection. 
We're doing something Spot physically cannot do — 
multi-modal ground-air coordination at squad level — 
at a price that makes fleet deployment possible."
```

### "The parts are cheap, so it must break easily"

**Response:**
```
"Every component is commercially validated. MG90S servos are in 
hundreds of thousands of drones worldwide. The Raspberry Pi 5 
is the most deployed single-board computer on Earth. 

If a leg breaks, you print a new one in thirty minutes. 
If a Spot leg breaks, you wait six weeks for a replacement 
and pay eight hundred dollars for shipping."
```

### "Why not just buy a DJI drone?"

**Response:**
```
"A DJI Matrice costs fifteen thousand dollars. It flies. 
It doesn't walk. It can't enter a building. It can't fold its legs 
and hide in rubble for thirteen hours. It can't carry a micro-drone 
swarm on its back.

SCOUT is a ground robot that happens to fly — 
not a drone that happens to have legs."
```
